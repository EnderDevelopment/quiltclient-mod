# QuiltClient Mod

A comprehensive Fabric client-side mod for Minecraft 1.21.11 with 200+ features.

## Features

- ClickGUI for easy access to all features
- Music player for in-game music
- Mod menu for managing mods
- Fullbright module for brighter gameplay
- Zoom module for enhanced viewing

## Requirements

- Java 21
- Gradle 8.8
- Minecraft 1.21.11

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/quiltclient-mod/releases).
2. Place the mod file in your Minecraft mods folder.
3. Launch Minecraft and enjoy the features.

## Usage

- Press the Right Shift key to open the ClickGUI.
- Press the M key to open the Music Player.
- Press the F8 key to open the Mod Menu.

## Configuration

The mod configuration is saved in the `quiltclientmod.json` file in your Minecraft directory. You can edit this file to customize the mod settings.
